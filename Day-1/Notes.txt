01. What is class in Java?

    - In simple terms, a class in Java is blueprint or template used to create objects.

    - Think of it as house construction plan
      a. Class: Blueprint of a house.
      b. Object: Actual house built using that blueprint.

    - Similarly, in Java:
      a. Class: Blueprint that defines properties (variables) and behaviours (methods).
      b. Object: An actual instance created using that class.

03. Variables

    - A Variable in Java is a container used to store data or information in a program.

    - Real-time Example:
        Imagine you are developing a Student Management System.

        You need to store:
            a. Student name
            b. Student age
            c. Student marks

06. Why we get Compilation Error in Java?

    - In Java, a Compilation Error occurs when your Java code violates Java's syntax rules, type rules, or 
      other compile-time rules.

    - In simple terms, Java checks your code before executing it. If it finds certain mistakes, it stops 
      compilation and displays an error.

    - Common reasons for compilation errors

        a. Missing semicolon
        b. Incorrect data type
        c. Incorrect variable declaration
        d. Using an undeclared variable
        e. Missing brackets

03. Primitive Data Types

    - Primitive data types are the 8 basic built-in data types provided by Java to store simple values.

    - Java has exactly 8 primitive data types.

    - They are:
        1. byte
            - Size: 1 byte (8 bits)
            - Range: -128 to 127
            - Used when you need to store small whole numbers.


        2. short
            - Size: 2 bytes (16 bits)
            - Range: -32,768 to 32,767
            - Used for whole numbers that are larger than the byte range but fit within the short range.


        3. int
            - Size: 4 bytes (32 bits)
            - Range: -2,147,483,648 to 2,147,483,647
            - Most commonly used integer data type in Java.


        4. long
            - Size: 8 bytes (64 bits)
            - Range: -2⁶³ to 2⁶³ - 1
            - Used for very large whole numbers.
            - Notice the L at the end.
            - Java uses L to identify a long literal.


        5. float
            - Size: 4 bytes (32 bits)
            - Precision: Approximately 6–7 decimal digits.
            - Used to store decimal numbers with single precision.
            - Notice the f at the end.


        6. double
            - Size: 8 bytes (64 bits)
            - Precision: Approximately 15–16 decimal digits.
            - Used for decimal values with double precision.


        7. char
            - Size: 2 bytes (16 bits)
            - Used to store a single UTF-16 code unit.
            - Values are written inside single quotes.
            - Single quotes are used for a char.
            - Double quotes are used for a String.


        8. boolean
            - Stores only two values: true or false.
            - Used for decision-making and conditions.
